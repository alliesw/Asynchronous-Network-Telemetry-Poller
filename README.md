Project: Asynchronous-Network-Telemetry-Poller
Author: Alex Shields-Weber 

Engineering Showcase & Project Artifacts -- designed to document continuous hands-on collaborative development (2024 – 2026).

Description: Features an interactive 2024–2026 project timeline, tech stack matrix, interactive SVG system architecture diagram, expandable code snippets, dark/light theme switching, & an integrated source code exporter—all packed into a single self-contained file.

Key Features Include:
--------------------------
(1) Multi-Year Interactive Timeline (2024–2026): Categorizes milestones from Phase 1 (Inception, Oct 2024) to Phase 4 (Production, 2026), with expandable details & active year filtering buttons.

(2) Interactive SVG System Architecture Diagram: Displays data flow from network end-devices into Python polling daemons, PostgreSQL storage, Splunk HEC alerting, & REST API/UI dashboards with click-to-inspect nodes.

(3) Interactive Code Snippet Viewer: Tabbed syntax-highlighted snippets for Python poller daemons, SQL table migrations, & GitHub Actions CI/CD workflows with copy capabilities.

(4) Built-in Source Exporter: An export modal & clipboard utility that copies the clean code template.

(5) Dark/Light Mode: Full dark mode support using Tailwind CSS with automatic system fallback.

(6) Tech Stack & Skills Matrix: Highlights Python, PostgreSQL, Splunk, Git/CI-CD, REST APIs, & Network Automation with visual progress indicators.
