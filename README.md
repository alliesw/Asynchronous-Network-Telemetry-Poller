# Asynchronous-Network-Telemetry-Poller

Engineering Showcase & Project Artifacts
> Designed to document continuous hands-on collaborative development (2024 – 2026).

- Features an interactive 2024–2026 project timeline, tech stack matrix, interactive SVG system architecture diagram, expandable code snippets, dark/light theme switching, and an
- integrated source code exporter—all packed into a single self-contained file.

Key Features Included:
--------------------------
Multi-Year Interactive Timeline (2024–2026): Categorizes milestones from Phase 1 (Inception, Oct 2024) to Phase 4 (Production, 2026), with expandable details and active year filtering buttons.

Interactive SVG System Architecture Diagram: Displays data flow from network end-devices into Python polling daemons, PostgreSQL storage, Splunk HEC alerting, and REST API/UI dashboards with click-to-inspect nodes.

Tech Stack & Skills Matrix: Highlights Python, PostgreSQL, Splunk, Git/CI-CD, REST APIs, and Network Automation with visual progress indicators.

Interactive Code Snippet Viewer: Tabbed syntax-highlighted snippets for Python poller daemons, SQL table migrations, and GitHub Actions CI/CD workflows with copy capabilities.

Built-in Source Exporter: An export modal and clipboard utility that copies the clean code template.

Dark/Light Mode: Full dark mode support using Tailwind CSS with automatic system fallback.
